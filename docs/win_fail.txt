Сохранённый вывод Windows при квоте Job Object 64 МиБ.
Это наблюдение кода ERROR_COMMITMENT_LIMIT, не рецепт исчерпания машины.
Текущая программа безлимитный запуск не принимает и выше HARD_CAP (256 МиБ) не выделяет.

Размер страницы: 4096 байт
Физическая память: 31862 МБ всего, 16494 МБ свободно
Выделение: VirtualAlloc, касание каждой страницы (запись нуля)
Квота процесса: 64 МБ (Job Object). Дальше VirtualAlloc должен вернуть ошибку.
Невозможно выделить память: VirtualAlloc(4194304 байт) вернул NULL, GetLastError()=1455
Сообщение ОС: Файл подкачки слишком мал для завершения операции.
ERROR_COMMITMENT_LIMIT (1455): система не может зарезервировать commit charge для региона.
Выделено и затронуто: 60.00 МБ в 15 регионах (дальше отказ ОС)
